## 🚀 Proyectos destacados

### 🎟️ Sortalia: plataforma de sorteos (app + web + API)
Producto completo con app móvil, sitio web y API compartida. Registro e inicio de sesión con email y Google, sorteos, compra de boletos con selección manual o automática de números, historial, panel de administración y auditoría de acciones sensibles.

- **API:** NestJS · PostgreSQL · Prisma · JWT · Argon2 · Zod · Helmet · rate limiting
- **Móvil:** React Native · Zustand · MMKV · NativeWind · Reanimated · React Hook Form
- **Web:** Next.js 16 (App Router) · Tailwind 4 · refresh de tokens *single-flight* en interceptores de Axios

`Next.js` · `Python` · `Gemini / OpenAI / Ollama` · `Chrome Extension`

`React Native CLI` · `TypeScript` · `AsyncStorage` · `GitHub Actions`
